# Sets (Python)

## Description
A simple Python program demonstrating set operations.

## Features
- Create Set
- Add Elements
- Remove Elements
- Union of Sets

## Technology Used
- Python

## Output
Original Set: {10, 20, 30}
After Add: {40, 10, 20, 30}
After Remove: {40, 10, 30}
Union: {1, 2, 3, 4, 5}
